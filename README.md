# SOOP Downloader

Android 앱에서 SOOP 다시보기·캐치 링크를 받아 제공되는 최고 화질을 기기에 저장합니다.

## 사용

- SOOP 영상 공유 → SOOP Downloader 선택 시 즉시 다운로드합니다.
- 앱에서 주소를 붙여 넣고 다운로드할 수도 있습니다.
- 저장 위치: Movies/SOOP Downloader.
- Android 10 이상. 별도 다운로드 서버를 사용하지 않습니다.

## 릴리즈 정책

이 저장소의 사용자 요청은 정식 릴리즈로 제공합니다. 동일 applicationId와 영구 서명 인증서를 유지하고 versionCode를 증가시킵니다. 키 설정과 실제 검증이 완료되기 전에는 APK를 정식으로 게시하지 않습니다.

현재 최초 버전 구현·검증 중입니다.
